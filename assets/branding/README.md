# Menu logos

The menu's text art is converted from these upstream assets, downloaded on
2026-09-15:

- [Herdr ram](https://herdr.dev/assets/ram.svg), used in the navigation on
  [Herdr's website](https://herdr.dev/). Saved here as `herdr-ram.svg`.
- [Omarchy logo](https://omarchy.org/brand/omarchy-logo.svg), from the
  [official brand page](https://omarchy.org/brand/). Saved here as
  `omarchy-logo.svg`.

The upstream SVGs are unchanged. Logos belong to their respective owners;
their use here identifies the products integrated by this community plugin.
The same source paths are used in the README cover, generated by
`scripts/generate-cover.py`. The cover is an illustration of the shortcut
profile. Brand assets and their derivatives are separate from the plugin
code's MIT license.

## Regenerate terminal art

From the plugin root on Omarchy:

```sh
omarchy transcode ascii assets/branding/herdr-ram.svg /tmp/herdr-ram-art.txt --width 20 --height 8 --mode braille
omarchy transcode ascii assets/branding/omarchy-logo.svg /tmp/omarchy-logo-art.txt --width 15 --height 8 --mode braille --no-trim
```

Copy the resulting lines into `herdr_shell/branding.py`. Herdr uses Unicode
braille cells to retain the curved horn at this size. Omarchy uses the same
braille texture, preserving its original square grid. Both use ordinary terminal
characters and theme colors; no private font glyphs or terminal image protocol
are required. The Python constants are bundled with the plugin so conversion
tools and network access are unnecessary when opening the menu.
